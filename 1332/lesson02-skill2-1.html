Skill 2.1: Describing Sets

Goal: describe a set in words, in roster form and in set-builder notation.

Set translator and natural-number rule builder

Every set can be described in words, by listing its elements (roster form), or by a rule (set-builder notation). Hide one way and try to recall it. Then build a set of natural numbers from a rule.

Questions to explore

Hide the roster for "ℕ greater than 6." What is the first element? Why not 6?

"Greater than 6" leaves 6 out, so the set starts at 7: {7, 8, 9, 10, …}. The … means the list goes on forever.

Look at "Letters of roof." Why does the roster have only three letters?

A set lists each element once. "roof" uses r, o, o, f, but the set is {r, o, f}.

In the rule builder, change "5 < x ≤ 8" to "5 ≤ x ≤ 8." What changes?

≤ includes the endpoint, so 5 joins the set: {5, 6, 7, 8}. With < the set was {6, 7, 8}.

Set the upper sign to (none). Why does the roster end with …?

With no upper limit the natural numbers keep going: {6, 7, 8, …} is an infinite set. You can't list it all, so … shows the pattern continues.
