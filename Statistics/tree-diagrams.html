Build the tree, label every branch, and read the marginal, conditional and joint probabilities straight off the picture.

Choose a problem

Each one runs through the same six steps: build the tree, fill the branches, work out the joint probabilities, answer questions, and then run the tree backwards.

Answer format. Every probability may be written as a fraction or as a decimal. Fractions need not be reduced — 4/6 and 2/3 both count. If you use decimal form, round to 4 decimal places (for example 0.6667, not 0.67).

Build the tree

Decide how many branches come out of each point, and name the outcome on each branch. Not every tree is a neat rectangle — if an outcome ends the experiment, give it zero branches.

Label every branch

Write the probability on each branch, then say what kind of probability it is. A branch leaving the starting point is a marginal probability. A branch further along depends on what already happened, so it is a conditional probability.

Fraction or decimal, your choice. Fractions need not be reduced. Decimals round to 4 places.

Joint probabilities

Follow each path from the start to its end and multiply the branches along the way. That product is the joint probability of the whole path — the chance that all of those things happen in that order.

The same numbers, arranged as a table

Click any cell to light up the path it came from. The four inner cells are the joint probabilities. The edges are the marginal probabilities, and the corner is always 1.

Run the tree backwards

Every branch on your tree points forwards in time: first this, then that. The interesting question usually runs the other way — you are told how things ended and asked what probably happened first. The tree answers that too, with no new formula.
