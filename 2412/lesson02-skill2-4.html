Skill 2.4: Radical & Rational-Exponent Equations

Goal: solve radical equations by isolating and raising to a power, check for extraneous solutions, and solve equations with rational exponents.

Squaring creates fakes

Compare the original equation with the squared one. Squaring keeps every real solution, but it can add new ones, because (−3)² = 3². That is why every answer must be checked in the original.

        Questions to explore

        On the "After squaring" graph, why are there two crossings when the original has one?

        Squaring the right side x + c turns its negative values positive, so the parabola picks up a crossing where x + c was negative. A square root is never negative, so that crossing cannot satisfy the original.

        In the solver, which exponents need a ±? Why?

        Those with an even numerator m, like 2/3 and 4/3: x^(2/3) = (∛x)², and both ∛x = 2 and ∛x = −2 square to 4.

        Why can x^(3/2) = −8 have no real solution?

        x^(3/2) = (√x)³ needs x ≥ 0, so it is never negative.
