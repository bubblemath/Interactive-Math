Skill 25.2: Series and Summation Notation

Goal: find partial sums, read and write sums in sigma notation, and evaluate sums with the summation properties and the formulas for Σk, Σk², and Σk³.

Partial sums

The nth partial sum adds the first n terms: Sₙ = a₁ + a₂ + ⋯ + aₙ. Watch what the sums do as n grows.

Open dots: the terms aₙ. Filled dots: the partial sums Sₙ.

Evaluate a sum with the formulas

Split the sum into pieces, pull out constants, then use Σ_(k=1)^(n) c = cn, Σ_(k=1)^(n) k = (n(n + 1))/2, Σ_(k=1)^(n) k² = (n(n + 1)(2n + 1))/6, and Σ_(k=1)^(n) k³ = ((n(n + 1))/2)².

Questions to explore

How many terms does Σ_(k=0)^(n) (k − 1)² have?

n + 1: k takes the values 0, 1, 2, …, n. In general a sum from k = m to k = n has n − m + 1 terms.

Why can we split Σ (k² − 7k + 2) into three sums?

Addition can be done in any order, so the k² parts, the −7k parts, and the 2s can be added up separately and then combined.

Why is Σ_(k=1)^(n) c equal to cn and not c?

The sum adds c once for each of the n values of k: c + c + ⋯ + c, n times.
