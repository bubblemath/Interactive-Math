Factor-out-b trainer

When the inside looks like 2x − 6, you must factor out b before you can read h. Try it.

Questions to explore

Does the order matter? Try (4, 2) on √x with b = 2 and h = 3.

Yes, inside the function. Divide by b first, then add h: 4 ÷ 2 + 3 = 5. Adding first gives (4 + 3) ÷ 2 = 3.5, which is wrong. Outside works the same way: multiply by a first, then add k.

Why can't you read h straight from √(2x − 6)?

The general form needs b(x − h). Factoring gives √(2(x − 3)), so h = 3. A quick check: the graph starts where the inside equals 0, and 2x − 6 = 0 gives x = 3, not 6.

Pick 1/x. Move all four sliders. Where do the asymptotes end up?

Always at x = h and y = k. Stretches and reflections don't move a line through the center; only the shifts do.

Which numbers can change the domain? Which can change the range?

Only the inside numbers, b and h, change x-values, so only they can change the domain (try √x). Only the outside numbers, a and k, can change the range.

Can two different equations draw the same graph?

Yes. |2(x − 1)| and 2|x − 1| are the same graph, because |2| comes out of the absolute value. That is why checking one more key point is a good habit.
