Skill 5.5: Even & Odd Functions

Goal: decide whether a function is even, odd, or neither, from its graph (symmetry) and from its equation (the f(−x) test).

Symmetry tester

Even: the graph is its own mirror image across the y-axis. Odd: turning the graph 180° about the origin gives the same graph. Use the buttons to test.

Set each coefficient. Terms with an even power are outlined solid; odd powers are dashed.

Even: the f(−x) column matches f(x). Odd: it matches −f(x).

Questions to explore

Choose "Build your own polynomial." When is it even? When is it odd?

If every term has an even power, it is even. A constant counts as an even power, because 5 = 5x⁰. If every term has an odd power, it is odd. Mix even and odd powers and it is neither.

Add a constant to an odd function, like x³ + 1. What happens?

It stops being odd. The constant is an even-power term, so you have a mix. On the graph, the shift up moves the center off the origin, so the rotation test fails.

Try √x. Why is it neither, even though it passes through the origin?

Its domain is [0, ∞). For x = 4, f(−4) does not exist, so f(−x) cannot equal f(x) or −f(x). A function can only be even or odd if its domain is symmetric about 0.

Can a graph be symmetric about the x-axis?

Not if it is a function (except y = 0). If (3, 2) and (3, −2) were both on the graph, it would fail the vertical line test.

Is an odd function always zero at x = 0?

Yes, if 0 is in its domain: f(0) = −f(0) forces f(0) = 0. So an odd graph that includes x = 0 must pass through the origin. 1/x is odd but skips x = 0 entirely.
