Skill 2.1: Reading & Graphing Inequalities

Goal: read an inequality aloud, graph it with the right circle and shading, and write the inequality shown by a graph.

Questions to explore

Graph x < 4 and x ≤ 4. What is the only difference?

The circle at 4. For x < 4 it is open, because 4 is not less than 4. For x ≤ 4 it is closed, because 4 is equal to 4. Test 4 in each to see.

Try the preset −3 > x. Why does the grapher rewrite it?

"−3 is greater than x" means x is smaller than −3, so x < −3. Flipping the whole statement, sides and symbol together, keeps it true and puts x first so you can read it.

Shortcut: when x is on the left, which way does the shading go?

The same way the symbol points. In x < 4 the symbol points left, so shade left. In x ≥ −3 it opens to the right, so shade right. This only works with x on the left.

Test 2 and 5 in the preset 2 < x ≤ 5. What happens?

2 fails (open circle: 2 is not greater than 2) and 5 passes (closed circle: 5 ≤ 5). Every number strictly between them passes too.
