Lesson 2 · subsets, proper subsets, ⊆ and ⊂ and ⊄

⊆ is ≤. ⊂ is <.

That one line settles nearly every question on this page. Just as 3 ≤ 3 is true while 3 < 3 is false, a set is always a subset of itself but never a proper subset of itself. Checking a subset is mechanical: walk through the elements of the first set one at a time and ask whether each one is also in the second. One failure is all it takes.

✋

Three things trip people up, and all three are cured by the ≤ analogy. A set is a subset of itself, because every element of it is in it — the same reason 3 ≤ 3 holds. The empty set is a subset of absolutely everything, because it has no element that could fail the test. And ⊂ is the stricter claim, so it can never be true when ⊆ is false. Whatever else you forget, remember that ⊂ demands everything ⊆ demands, and then one thing more.

Why it matters

Containment is the shape of most mathematics

01

Every square is a rectangle

Classification claims are subset claims. Once the notation clicks, sentences like that one stop being memorized facts and start being checkable.

02

The empty set is not a special case

It follows the ordinary rule. Nothing in it can fail the test, so it passes for every set there is — including itself.

03

⊆ and ∈ are next

The notation people confuse most is set-versus-set against element-versus-set. Being fluent with ⊆ first makes that distinction visible.
