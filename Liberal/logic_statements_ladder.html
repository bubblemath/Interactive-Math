Lesson 6 · statements, negations, and the sentences that are neither

No truth value, no negation.

Logic works on statements — sentences that are either true or false, and never both. Questions, commands, exclamations and opinions all look like ordinary English, but none of them has a truth value, so none of them can be negated. And when a sentence is a statement, negating it does exactly one thing: it flips that truth value, leaving everything else about the sentence alone.

Negating is not the same as writing the opposite. The negation of “The Astros won the World Series in 2017” is “The Astros did not win the World Series in 2017” — not “The Astros lost.” Winning and losing are not the only two possibilities, so both of those could be false at once, and two statements that can both be false are never negations of each other. That single test settles most of this lesson.

Why it matters

Everything after this is built on negation

01

Quantifiers are next

Negating “all,” “some” and “no” is the same operation, applied to sentences where the wrong answer feels much more natural.

02

De Morgan returns

The rules you proved with Venn regions turn into rules about “and,” “or” and “not.” They are the same rules.

03

Truth tables need truth values

A sentence with no truth value has no column. Deciding what counts as a statement is the first move, every time.

Ask whether it can be true or false. If it can, flip that and change nothing else.
