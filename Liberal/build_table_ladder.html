Lesson 8 · building a truth table column by column

Innermost first, one column at a time.

Nobody fills in the last column directly. You work outward from the smallest pieces: every bracket gets its own column, every ~ gets its own column, and each new column is built only from columns already sitting on the page. Do that and the final column is one easy step, not one hard one.

✋

A column can only be built from columns you already have. That single rule fixes the whole order: p ∨ q and ~p come first because they need only the base columns, the bracket that joins them comes next because it needs those two, and the arrow comes last because it needs the bracket. Skip a step and there is nothing on the page to read from.

How it works

Climb it, or jump to the rung that trips you up

Rungs 1–2 lay out the rows and the base columns. Rungs 3–5 build a negation, an innermost bracket, and then join two finished columns. Rungs 6–10 work a single row, put a build in order, extend to three letters, and hunt a wrong cell.

Why it matters

The order is the method

01

Big statements stop being big

A statement with four connectives is four small columns. None of them is harder than the two-letter tables you already know.

02

Mistakes stay findable

With every step written down, a wrong final column can be traced back to the column where it went wrong.

03

Eight rows are no harder than four

The same columns, twice as tall. Only the base columns change when a third letter appears.

Build what the brackets ask for first. Every later column reads only from ones already on the page.
