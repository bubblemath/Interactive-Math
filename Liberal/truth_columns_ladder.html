Lesson 8 · the five connective columns, four rows at a time

Learn the odd row out.

You never have to memorise four cells. Each connective has one short rule, and for three of the five that rule names a single row: p ∧ q is true in one row only, p ∨ q is false in one row only, and p → q is false in one row only. Find the odd row and every other cell follows.

✋

The conditional is the one that will not feel right, and it is not supposed to. p → q is false in exactly one row — the one where p is true and q is false. In both rows where p is false the conditional comes out true, because a promise conditional on something that never happened was never broken. Those two rows are where nearly every wrong truth table starts.

How it works

Climb it, or jump to the rung that trips you up

Why it matters

Five rules, and everything else is bookkeeping

01

Big tables are small ones repeated

A statement with three connectives is these five rules applied three times, one column at a time.

02

One wrong cell changes the verdict

Whether a statement is a tautology is decided by the final column. A single miscopied row can flip the answer.

03

Equivalence is column matching

Two statements mean the same thing when their final columns agree, which is how De Morgan's laws get proved here.

One rule per connective. Find the odd row, fill it in, and the rest of the column writes itself.
