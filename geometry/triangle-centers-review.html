1. Midpoint and slope: get these right first

Midpoint: average the coordinates

M = ( (x₁ + x₂) / 2 , (y₁ + y₂) / 2 )

Example: A(0, 8) and B(8, 0) → ((0 + 8)/2, (8 + 0)/2) = (4, 4)

Common mistake: subtracting. The midpoint adds the coordinates and divides by 2. Subtracting is for slope.
Sanity check: the midpoint has to land between the two points.

Slope: rise over run, in the same order

m = (y₂ − y₁) / (x₂ − x₁)

Example: B(8, 0) and C(12, 8) → (8 − 0)/(12 − 8) = 8/4 = 2

Common mistake: mixing up the order, or rushing the bottom subtraction. If you start with point C on top, start with point C on the bottom too.

Perpendicular slope: flip it AND change the sign

2 → −1/2  ·  −3/4 → 4/3  ·  −1 → 1

Special cases
Horizontal side (slope 0) → its perpendicular bisector is vertical:  x = (midpoint's x)
Vertical side (undefined slope) → its perpendicular bisector is horizontal:  y = (midpoint's y)

2. Writing a perpendicular bisector equation

  1. Find the midpoint of the side.
  2. Find the slope of the side.
  3. Find the perpendicular slope (flip it and change the sign).
  4. Plug the midpoint (not a vertex!) and the perpendicular slope into point-slope form: y − y₁ = m(x − x₁)
  5. Simplify to y = mx + b.
Example: side BC with B(8, 0) and C(12, 8)
Midpoint = ((8 + 12)/2, (0 + 8)/2) = (10, 4)
Slope = (8 − 0)/(12 − 8) = 8/4 = 2
Perpendicular slope = −1/2
y − 4 = −1/2(x − 10)
y − 4 = −1/2x + 5 → y = −1/2x + 9

3. Finding the circumcenter from coordinates

  1. Write the perpendicular bisector equations (you need at least two).
  2. Solve two of them together. If one is vertical (x = __) or horizontal (y = __), start with it. Just substitute.
  3. Check the point with the third equation. All three bisectors must pass through it.

Worksheet #1: A(0, 8), B(8, 0), C(12, 8) → bisectors y = x, y = −1/2x + 9, and x = 6.
Substitute x = 6 into y = x → (6, 6). Check: −1/2(6) + 9 = 6 ✓

Extra check: the circumcenter is the same distance from all three vertices.

6. Distance problems (Pythagorean theorem inside the diagram)

Circumcenter problems

The radius goes from the center to a vertex. A perpendicular bisector cuts its side in half, which makes a right triangle:

(half the side)² + (center-to-side distance)² = radius²

Example: XY = 24 and JQ = 5 → half of XY is 12 → QX = √(144 + 25) = √169 = 13.
XZ = 22 → half is 11 → QK = √(169 − 121) = √48 ≈ 6.9

Subtract carefully: 169 − 121 = 48, not 148.

Incenter problems

The incenter is the same distance from every side, and those distances are perpendicular. If GD = 9, then GE = GF = 9.

Given the distance to a vertex (like BG)? It's the hypotenuse: leg² + leg² = BG².

Inscribed circle facts

A radius drawn to a point of tangency is perpendicular to the side (so m∠OFB = 90).
Two tangent segments from the same vertex are equal.

Right triangle shortcut: r = (a + b − c)/2. For 3-4-5: r = (3 + 4 − 5)/2 = 1

Centroid

AG = 2 · GD  and  AD = 3 · GD
