Every classification starts the same way:
subtract first, then divide.

There are only four answers on this whole ladder — arithmetic, geometric, recursive, or neither. You never guess between them. You run one test: subtract consecutive terms. Constant difference? Arithmetic. If not, divide. Constant ratio? Geometric. Still nothing? The pattern is hiding in the differences of the differences.

Subtract. If the gaps are equal, you're done.
Gaps are all +3 → Arithmetic.
Gaps not equal? Divide instead.
Differences grow — but every ratio is ×2 → Geometric.
✋

Decreasing does not mean arithmetic. A sequence like 256, 128, 64, 32 is shrinking, so the instinct is to say "subtract." But the gaps (−128, −64, −32) aren't equal — the ratio is. It's geometric with r = ½. Confusing the common difference with the common ratio is the single most common mistake on this material, and this ladder is built to break the habit.

Why it matters

Classification is the skill under the skill

You can't compute what you can't name

The nth-term formulas only work once you know the type. aₙ = a₁ + d(n−1) is useless if the sequence was geometric all along.

The tests ask for it directly

"Arithmetic, geometric, recursive, or neither?" is a standard K–6 item. Your students will meet it, and so will you when you teach it.

Differences are a general tool

When neither test works, the differences of the differences almost always do. That's how you crack squares, triangular numbers, and more.

Intuition says a shrinking sequence must be subtraction, and that a sequence that starts 2, 3, 6 must be adding. Both are wrong, and both are wrong for the same reason: intuition skipped the test. Run the test — subtract, then divide — and the four answers sort themselves out.
