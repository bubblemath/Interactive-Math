Math 1350 · Lesson 12 · the real number system

Not which box —
how many.

The sets nest. Every natural number is whole, every whole number is an integer, every integer is rational, and every rational is real. So 4 does not belong to one of these sets — it belongs to all five at once, and the useful question is never “which box?” but “how many boxes is it inside?”

✋

Students answer “4 is a natural number” and stop, as though that ruled the others out. It does not — 4 is natural and whole and an integer and rational and real, all simultaneously, because each set sits inside the next. Two numbers carry most of the difficulty. 0 is whole but not natural, since the counting numbers begin at 1; and −3 is an integer but not whole. Those two boundaries are where the nesting is actually tested. And the irrationals do not nest. Every other set in the picture is contained in the one outside it, so students expect 𝕀 to sit inside ℚ too. It does not — ℚ and 𝕀 share nothing at all, and together they make up ℝ exactly. Every real number is one or the other, never both and never neither.

Why it matters

Each set exists because the last one ran out

Subtraction built the integers

3 − 5 is a perfectly sensible question with no whole-number answer. The negatives were invented so that it would have one.

Division built the rationals

3 ÷ 5 has no integer answer. Fractions exist so that dividing is always possible — except by zero.

Roots built the reals

√2 has no rational answer, and yet it is the diagonal of a unit square. The irrationals fill the gaps the fractions leave behind.

The number system grew outwards, each layer added because a question you could ask in the old one could not be answered there. Ask what a number is made of, then read off every set that contains it — the answer is almost never just one.
