Partial products, the area box, the lattice, the standard algorithm \u2014 all four multiply the same pairs of digits and add the same four numbers. They differ only in where on the page those numbers get written. Learn to see the four products underneath and every algorithm becomes the same algorithm.

Four arrangements. The same four products. The same 322.
✋

The placeholder zero is not a formality. In 14 \u00D7 23 the second row is 280, because you are multiplying by the 20 \u2014 not by the 2. Drop the zero and you get 42 + 28 = 70 instead of 322. It looks like a slip of the pen and it is really a place-value misunderstanding: the student does not know what the 2 in 23 is worth. Every other algorithm on this page makes that value visible, which is exactly why they are worth teaching.

Why it matters

The standard algorithm hides what the others show

Efficiency costs visibility

The standard algorithm is the fastest and the most opaque. A child who only meets that one has no picture to fall back on when the steps blur.

Alternatives are diagnostic

Ask a struggling student to try the area box. If the four products are right but the columns were wrong, you have found a place-value problem, not a facts problem.

They all rest on distribution

14 \u00B7 23 = (10 + 4)(20 + 3). Every algorithm here is that expansion, written in a different shape.

Four methods look like four things to memorise and are really one idea wearing four coats. Find the partial products, check each one against the place value that produced it, and the placeholder zero stops being a rule you forget.
