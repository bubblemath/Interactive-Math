Every division asks
the same question: is there a unique c?

a ÷ b is the whole number c for which b · c = a. Run that one test and all four awkward cases sort themselves out — including the two that fail, which fail for opposite reasons.

one test, four outcomes
is there a unique whole number c with b · c = a ?
✋

“Undefined” hides two completely different failures. For 5 ÷ 0 you need 0 · c = 5, and no whole number does that — there are no answers at all. For 0 ÷ 0 you need 0 · c = 0, and every whole number does that — there are far too many. One is empty, the other is overcrowded, and the word “undefined” covers both without explaining either. This is exactly why the definition insists the c be unique.

Why it matters

Where the definition earns its keep

“Uniqueness” is not decoration

It is the word that separates 0 ÷ 0 from every well-behaved division. Drop it and the definition breaks.

The properties save real work

Knowing d | a and d ∤ b forces d ∤ (a+b) lets you rule out divisors of huge sums without adding anything.

Children ask about zero

“Why can’t you divide by zero?” is one of the most common questions in elementary classrooms, and “you just can’t” is not an answer.

Division by zero is not a rule someone imposed — it is what happens when you ask for a unique answer and the arithmetic offers none, or offers all of them at once. Run the test — is there a unique c with b · c = a? — and every case here answers itself.
