Decision guide

Step 1 — Can you do arithmetic?

Ask: does adding or averaging this variable produce a meaningful number? If no → qualitative. If yes → quantitative.

Step 2 — Counted or measured?

If quantitative: can you list all possible values? Counted things (people, goals, accidents) → discrete. Measured things (height, time, temperature) → continuous.

Numbers that aren't quantitative

Zip codes, phone numbers, jersey numbers, and SSNs are stored as digits but label or identify — adding two zip codes is meaningless. Classify by purpose, not appearance.

The "between" test for continuous

A variable is continuous if there is always another possible value between any two values. Between 1.5 m and 1.6 m there is 1.55 m — height is continuous.

💡
Quick test: "Can I average it and get something meaningful?" Average shoe size → yes (quantitative). Average eye color → nonsense (qualitative). If the average is meaningless, the variable is qualitative.
⚠️
Classic trap: Zip codes, jersey numbers, and Social Security numbers look quantitative but are really qualitative — they name or identify, they don't measure. Always ask: "Does the number's size matter?"
