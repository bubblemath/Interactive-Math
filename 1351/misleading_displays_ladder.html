Spot the Lie in the Graph

Ten rungs on recognizing distorted axes, manipulated scales, misleading pictographs, disproportionate area/size comparisons, and missing context — the five tricks graphs use to deceive.

📏
Broken / Truncated Y-Axis
Y-axis doesn't start at zero, making small differences look dramatic. Most common deception in bar and line charts.
📐
Non-Uniform Scale
Unequal intervals on an axis — the gaps between tick marks are not the same size — distorting growth or trends.
🖼️
Misleading Pictograph
When an icon doubles in height to show a doubling in value, its area quadruples — making the difference look 4× instead of 2×.
🔵
Disproportionate Area / Size
3D pie charts, unequal pie slices tilted toward the viewer, or bubbles scaled by radius instead of area all exaggerate some values.
🔍
Missing Context / Labels
No axis title, no units, no data source, cherry-picked time range, or omitted comparison group makes a graph uninterpretable.
📏
Truncated y-axis test: Does the y-axis start at zero? If not, ask: does starting at a higher value make a small change look large? If yes — that's misleading.
🖼️
Pictograph area rule: When an icon is scaled in 2D, doubling the height also doubles the width → area increases by 2² = 4×. Only scaling by area (not height) gives an accurate visual comparison.
🔍
Context checklist: Every graph needs axis titles, units, a data source, a complete time range, and an appropriate comparison group. Missing any of these makes the graph potentially misleading.
