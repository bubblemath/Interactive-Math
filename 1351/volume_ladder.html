Ladder 25 — Volume of Solids

Volume measures how much 3-D space a solid occupies — always in cubic units. Most volume formulas share a single idea: Volume = Base Area × Height. Cones and pyramids are exactly one-third of the prism or cylinder with the same base. Earn a badge on each rung by answering 4 in a row correctly.

Volume Formulas
SolidFormulaKey Variables
Rectangular PrismV = lwhl = length, w = width, h = height
CubeV = s³s = edge length
Triangular PrismV = ½bh × db, h = triangle base & height; d = depth/length
CylinderV = πr²hr = base radius, h = height
ConeV = ⅓πr²hr = base radius, h = vertical height
Square PyramidV = ⅓s²hs = base side, h = vertical height
SphereV = (4/3)πr³r = radius
Key Relationships
PairRelationship
Cone vs. CylinderSame base & height → V_cone = ⅓ V_cylinder
Pyramid vs. PrismSame base & height → V_pyramid = ⅓ V_prism
Radius vs. Diameterr = d ÷ 2; always divide diameter by 2 first
UnitsVolume is always cubic: ft³, cm³, in³, m³ …
💡
One-third rule. A cone holds exactly ⅓ as much as a cylinder with the same radius and height. A pyramid holds exactly ⅓ as much as a prism with the same base area and height. This is always true, regardless of shape.
⚠️
Cubic units! Surface area uses square units (ft²). Volume uses cubic units (ft³). Never mix them up — if your answer is in ft² for a volume problem, something went wrong.
📐
Composite volumes. Break the solid into recognizable pieces, find each volume separately, then add (or subtract for hollow sections). Label every piece before computing.
