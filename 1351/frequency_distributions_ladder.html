Math 1351 · Lesson 3 · frequency distributions
f/n

Group it. Count it. Summarize it.

Ten rungs on building and reading grouped frequency distributions — class width, midpoints, boundaries, frequencies, relative frequencies, and cumulative frequencies. Numbers first, explanations after.

Class Width
width = (max − min) ÷ k
Round UP to a convenient whole number. k = number of classes (typically 5–20).
Class Midpoint
m = (lower + upper) ÷ 2
Average of the lower and upper class limits. Used as the x-value in histograms and polygons.
Relative Frequency
rf = f ÷ n
f = class frequency, n = total observations. Expresses each class as a proportion of the whole. All rf values sum to 1 (or 100%).
Cumulative Frequency
cf = Σ f (up through class)
Running total of frequencies from the first class through the current class. The last cumulative frequency always equals n.
Class Boundaries
LB = lower − 0.5, UB = upper + 0.5
Eliminate gaps between classes. Used on histogram axes. Also called true class limits.

Frequency Distribution Components

TermDefinitionExample (class: 60–69)
Class LimitsThe lowest and highest values that belong to a class as written in the tableLower: 60, Upper: 69
Class BoundariesLimits adjusted ½ unit outward to eliminate gaps; used on histogram axesLB: 59.5, UB: 69.5
Class WidthDistance from one lower boundary to the next; all classes must have equal width69.5 − 59.5 = 10
Class MidpointCenter of a class; used as the representative value for that class(60 + 69) ÷ 2 = 64.5
Frequency (f)Count of data values falling within a classf = 18
Relative FrequencyFrequency as a proportion of the total: rf = f / n18 / 90 ≈ 0.200
Cumulative FrequencyRunning total of frequencies from the first class through the current classΣf = 45 (through this class)
📐
Width rounding rule: Always round class width UP, never down. Rounding down can leave some data values without a class; rounding up ensures all values are covered.
⚠️
Last cf = n: The cumulative frequency of the last class must equal the total number of observations. If it doesn't, you made an arithmetic error.
🔢
Boundaries vs. limits: Class limits are the values as written (60–69). Class boundaries extend ½ unit each way (59.5–69.5). Histograms use boundaries so bars touch.
