P(x)

Assign a probability to every possible outcome.

Ten rungs — from reading a distribution table and verifying one is valid, to building binomial distributions and finding cumulative probabilities. Earn a badge by getting 4 in a row.

Valid Distribution
Each P(x) ≥ 0
ΣP(x) = 1
Every probability is non-negative
and all probabilities sum to exactly 1.
Binomial Formula
P(x) = C(n,x) · pˣ · (1−p)ⁿ⁻ˣ
n = trials, x = successes, p = P(success)
Each trial independent; only 2 outcomes.
Binomial Mean & SD
μ = np
σ = √(np(1−p))
Expected successes = np.
Spread = √(npq) where q = 1−p.

Key ideas

Discrete random variable

A variable X that takes a countable set of values. A probability distribution lists every value x and its probability P(x).

Validity check

Two conditions: (1) every P(x) is between 0 and 1, and (2) all P(x) values sum to exactly 1. Fail either → not a valid distribution.

Binomial conditions (BINS)

Binary outcomes · Independent trials · Number of trials fixed · Same probability each trial.

Cumulative probability

P(X ≤ k) = sum of P(x) for all x from 0 to k. "At most k" → add up; "at least k" → use complement.

💡
Binomial shortcut: When you need P(X = 0) or P(X = n), the formula simplifies — C(n,0) = C(n,n) = 1, so P(X=0) = (1−p)ⁿ and P(X=n) = pⁿ. Use these to anchor complement calculations quickly.
⚠️
Common mistake: Forgetting to include C(n, x) in the binomial formula. The combination counts how many ways to arrange x successes among n trials — without it you only get the probability of one specific sequence, not all of them.
