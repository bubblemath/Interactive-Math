Read the display; extract the fact.

Ten rungs of stem-and-leaf plots, dot plots, frequency tables, bar charts, and histograms. Every question gives you an actual display — your job is to read a value, find a count, or compute a relative frequency directly from what you see.

Stem-and-Leaf
Each data value split into a stem (leading digit) and leaf (last digit). Preserves raw values; shows shape.
Quantitative data only
Dot Plot
Each data value marked as a dot above a number line. Easy to see clusters, gaps, and outliers.
Small datasets, quantitative
Frequency Table
Tallies how many values fall in each class or category. Foundation for histograms and relative frequency.
Any data type
Bar Chart
Bars for qualitative categories separated by gaps. Bar height = frequency or relative frequency.
Qualitative (categorical)
Histogram
Bars for quantitative class intervals — no gaps. Bar height = frequency for that class.
Quantitative, grouped

Quick-read checklist

Stem-and-leaf

Read stem | leaves. Each leaf is one data value. Stem 4 | 2 7 means the values 42 and 47. Count leaves to find how many values are in a row.

Dot plot

Count the dots above a value to get its frequency. Stack height = count. Total dots = total n.

Frequency table

Relative frequency = class frequency ÷ total n. All relative frequencies must sum to 1 (100%).

Bar chart vs. histogram

Gaps between bars → bar chart, categorical data. No gaps → histogram, quantitative classes. Heights are read the same way: height = count.

💡
Stem-and-leaf tip: To find the median, count the total number of leaves (= n). The median is the middle leaf when all are in order — stems go top to bottom, leaves go left to right within each row.
⚠️
Common error: Relative frequency is a proportion (0 to 1), not a count. If 12 out of 40 data values fall in a class, the relative frequency is 12/40 = 0.30, not 12.
