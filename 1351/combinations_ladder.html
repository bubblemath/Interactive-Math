C(n, r) — Combination
C(n,r) = n! / (r!(n−r)!)
Choose r items from n, order does NOT matter.
Also written ⁿCᵣ, nCr, or (n choose r).
C vs P — The Key Question
Does swapping two items
change the outcome?
Yes → Permutation (order matters).
No → Combination (order doesn't matter).
Multi-group Selection
C(n₁,r₁) × C(n₂,r₂) × …
Select independently from each group,
then multiply by the Multiplication Principle.

Key ideas

Order doesn't matter

A committee of {Alice, Bob, Carol} is the same as {Carol, Alice, Bob}. Swapping members doesn't create a new committee → use C(n, r).

Why divide by r!

A permutation counts every ordering of the r chosen items. Since order doesn't matter here, we divide by r! to collapse all those duplicates into one group.

Symmetry shortcut

C(n, r) = C(n, n−r). Choosing 2 from 10 gives the same count as leaving 8 behind: C(10, 2) = C(10, 8) = 45.

Multi-group problems

When selecting from separate groups (e.g., 2 men and 3 women from different pools), compute each C independently, then multiply.

⚠️

Most common mistake: Using P(n, r) when order doesn't matter. If you're forming a committee, choosing a hand of cards, or picking a group with no roles assigned, the answer is C(n, r) — not P(n, r). Ask yourself: does it matter which slot each person fills? If not, divide out the r! extra orderings.
