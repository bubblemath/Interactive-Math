P(n,r)

Order matters — count every arrangement.

Ten rungs — from computing factorials to selecting and arranging objects, including repeated elements. Earn a badge by getting 4 in a row on each rung.

n! — Factorial
n! = n × (n−1) × … × 2 × 1
0! = 1 by definition.
Counts all arrangements of n distinct items.
P(n, r) — Permutation
P(n,r) = n! / (n−r)!
Choose r items from n, order matters.
Also written ⁿPᵣ or nPr.
Distinguishable Perms
n! / (n₁! × n₂! × … × nₖ!)
When some items are identical, divide out the repeats.

Key ideas

Factorial

n! counts the ways to arrange all n distinct objects in a row. Example: 4! = 4 × 3 × 2 × 1 = 24.

Permutation

P(n, r) counts arrangements of r objects chosen from n distinct ones. Order matters — ABCD ≠ DCBA.

Distinguishable

When items repeat (like letters in MISSISSIPPI), identical copies create duplicate arrangements that must be divided out.

Order matters?

If swapping two items gives a different outcome (a different medal, a different word), you need a permutation, not a combination.

⚠️

Most common mistake: Forgetting to divide by (n−r)! when using the permutation formula. P(n, r) is not the same as n!. If you're arranging all n items, P(n, n) = n!, but if you're only choosing r of them, you must divide: P(n, r) = n! ÷ (n−r)!
