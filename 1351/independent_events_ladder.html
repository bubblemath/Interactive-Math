Math 1351 · Lesson 1 · independent vs. dependent events
A⊥B

Does knowing one event happened change the chances of the other?

Ten rungs — classify events, apply the independence test, multiply along tree branches, and find the probability of sequences with and without replacement. Earn a badge on each rung by getting 4 in a row.

✓ Independent Events
P(A ∩ B) = P(A) · P(B)
Knowing A occurred does NOT change P(B).
With replacement → always independent.
⚠ Dependent Events
P(A ∩ B) = P(A) · P(B | A)
Knowing A occurred DOES change P(B).
Without replacement → always dependent.
🔬 Independence Test
P(B | A) =? P(B)
Equal → independent.
Not equal → dependent.

How it works

01 / Ask the key question

Does the first event change the sample space for the second? If yes → dependent.

02 / With or without replacement?

With replacement: n(S) stays the same each draw → independent. Without: n(S) shrinks → dependent.

03 / Tree diagram

Write each branch's probability. For dependent events, second-level probabilities change based on the first branch taken.

04 / Multiply along the branch

P(path) = product of all branch probabilities on that path from root to leaf.

⚠️

Most common mistake: Using the same probability for the second draw when drawing without replacement. After removing a card or marble, n(S) decreases by 1 AND n(event) may decrease by 1 — both the numerator and denominator can change.
