Box Plots & Five-Number Summary

Ten rungs from extracting the five-number summary and computing IQR fences, to identifying outliers and reading distribution shape from a box plot.

Min
Minimum
Smallest value in the data set
Q1
1st Quartile
Median of lower half (25th percentile)
Q2
Median
Middle of sorted data (50th percentile)
Q3
3rd Quartile
Median of upper half (75th percentile)
Max
Maximum
Largest value in the data set
⚠️
Outlier fences: Lower fence = Q1 − 1.5·IQR  |  Upper fence = Q3 + 1.5·IQR. Any value outside these fences is a mild outlier and is plotted as an individual point.
📌
Shape from a box plot: If the median line is closer to Q1, the data is right-skewed. Closer to Q3 → left-skewed. Centered → roughly symmetric.
💡
Whiskers reach: the most extreme value that is still INSIDE the fences — not necessarily the min/max if outliers exist.
