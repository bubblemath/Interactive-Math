Ladder 15 — Translations

Slide every point the same distance in the same direction. Master the notation, apply the rule, find the rule from a picture, and reason about what translations preserve. Earn a badge on each rung by answering 4 in a row correctly.

Translation Reference
ConceptNotation / RuleWhat it means
Translation rule(x, y) → (x + a, y + b)Every point moves right a (or left if a < 0) and up b (or down if b < 0)
Image notationA → A′ ("A prime")A′ is the image of pre-image A after the transformation
Finding the rulea = x′ − x, b = y′ − ySubtract pre-image coordinates from image coordinates
Composing translations(x+a, y+b) then (x+c, y+d) = (x+(a+c), y+(b+d))Two translations combine into one net translation
Inverse translationUndo (x+a, y+b) with (x−a, y−b)Move back by the same amounts in the opposite direction
💡
Shape is preserved. A translation slides — it never rotates, reflects, or resizes. The image is congruent to the pre-image, with the same orientation.
⚠️
Sign matters. Moving left means a is negative; moving down means b is negative. Read the rule carefully before applying it.
📐
Every point moves equally. All vertices shift by the same (a, b). If one vertex is right, they all are — use any vertex pair to find the rule.
