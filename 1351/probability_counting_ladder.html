Math 1351 · Lesson 2 · probability using counting principles
P(E)

Count the favorable outcomes. Count the total. Divide.

Ten rungs — from basic equally-likely outcomes to multi-step, complement, and conditional probability problems solved with permutations and combinations. Earn a badge by getting 4 in a row.

Classical Probability
P(E) = n(E) / n(S)
n(E) = favorable outcomes
n(S) = total equally-likely outcomes
Using Counting
n(E) = C(n,r) or P(n,r)
n(S) = C(n,r) or P(n,r)
Use permutations when order matters.
Use combinations when it doesn't.
Complement Rule
P(E) = 1 − P(Eᶜ)
Often easier: subtract from 1
when "at least one" or "at least k" appears.

Strategy for every problem

Step 1 — count n(S)

How many total equally-likely outcomes are there? Does order matter? Use P or C to count the entire sample space.

Step 2 — count n(E)

How many of those outcomes satisfy the event? Apply the same counting tools — multiply stages when needed.

Step 3 — divide

P(E) = n(E) / n(S). Leave as a simplified fraction, or round to 4 decimal places when asked for a decimal.

Complement shortcut

When the event says "at least one" or "at least k," compute 1 − P(none / fewer than k). This is almost always shorter.

💡
Order check: Ask "does swapping two items change the outcome?" — Yes → permutation sample space; No → combination sample space. Both numerator and denominator must use the same counting method.
⚠️
Common mistake: Using different counting methods for n(E) and n(S). If the sample space is ordered arrangements, n(E) must also count ordered arrangements — not unordered groups.
